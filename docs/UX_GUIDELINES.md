# Diretrizes de UX

## Acoes destrutivas

Toda acao que possa apagar, descartar, sobrescrever ou tornar dados indisponiveis deve exigir confirmacao explicita antes de ser concluida.

Exemplos:

- excluir anotacao;
- excluir container de inventario;
- descartar item;
- remover carta, habilidade ou experiencia;
- resetar dados de personagem.

A confirmacao deve deixar claro o que sera perdido e, quando aplicavel, se a acao nao podera ser desfeita.
